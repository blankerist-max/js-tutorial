## 這個網站是怎麼來的？

我也是 JavaScript 初學者。這些教材的製作流程是：

1. **先自己學**：用這份教材學一次，把卡關的地方記在[學習日誌](/journal/)。
2. **驗證有沒有效**：看完之後，能不能不看答案寫出練習題？隔一週還記得嗎？
3. **有效就分享，沒效就改**：回頭修改教材，直到它真的能讓人學會。

教材撰寫過程中有使用 AI 輔助，所有內容都會對照 [MDN 文件](https://developer.mozilla.org/zh-TW/docs/Web/JavaScript)檢查，範例也都實際執行過。如果你發現錯誤，非常歡迎告訴我。
